APK находятся в папке Releases. Для установки запускаем файл install.sh или install.bat в зависимости от ОС.

Системное приложение устанавливается копированием в папку /system/priv-app/Native устанавливается оно после перезагрузки. После установки регистрируется слушатель на системный броадкас BOOT_COMPLETED. И только после второй перезагрузки запускается сервис!
