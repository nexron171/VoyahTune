# HTML-прототип обновлений VoyahTune

Откройте `index.html` прямо в браузере. Сборка, зависимости и сеть не нужны.
При необходимости HTTP-просмотра из корня проекта:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory tmp/ota-updater-prototype
```

Макет основан на палитре и структуре Installer/desktop/src/styles.css:
тёмный фон, бирюзовый акцент, шкала этапов, панели и нижняя строка действий.
Холст 1920 × 720 масштабируется под окно. Слева зарезервировано 145 px
под док, сверху 32 px под условную системную панель. Это иллюстрация,
реальные Android WindowInsets надо сохранить при переносе дизайна.

## Просмотр

- Список «Состояние» переключает все основные экраны без ожидания.
- «Скачать» демонстрирует загрузку и проверку, затем ждёт подтверждения установки.
- «Установить» открывает подтверждение. Далее показаны подготовка, установка,
  перезагрузка, проверка запуска и успех. Реальной перезагрузки нет.
- «Автопрогресс» включает/приостанавливает развитие демонстрационного сценария.
- При ошибке причина показана прямо на экране; предложена установка через USB.
- Настройки содержат адрес каталога и повторную установку текущей версии.
  Адрес хранится только в памяти страницы и не используется для сетевых запросов.
- «Уведомление о релизе» показывает скрываемый диалог; скрытие ничего не скачивает.
- «В VoyahTune» показывает подсказку вместо открытия реального приложения.

Версии, размер, часы, ошибки и состояния службы — демонстрационные значения.
Описание изменений релиза не выдумывается: каталог его сейчас не содержит.

## Обновление экрана

Периодический опрос имитируется каждые 2 секунды. Элементы DOM постоянны,
текст и прогресс изменяются только при отличии значения. Доступность действий
зависит от этапа операции, а не от каждого запроса состояния. Нет общей
анимации появления, сброса фокуса или пересоздания экрана при опросе.

Это предложение поведения для переноса в MainActivity, не исправление
реального Android UI. APK апдейтера и root-служба не изменены; возможность
OTA-обновления самого апдейтера не добавлялась. Пересборка APK, payload и
десктопного установщика для прототипа не требуется.
