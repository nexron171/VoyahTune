OPEN VOYAH — УСТАНОВКА И УСТРАНЕНИЕ ОШИБОК
============================================================

ВАЖНО
------------------------------------------------------------
Перед началом полностью остановите автомобиль, переведите селектор в режим P и включите стояночный
тормоз. Не выполняйте установку во время движения. Не отключайте питание и USB во время установки
и перезагрузки головного устройства.

Распакуйте ZIP полностью в отдельную папку. Не запускайте файлы прямо из окна архиватора.
Путь к папке лучше сделать коротким и простым, например C:\VoyahTune на Windows или
~/Downloads/VoyahTune на macOS. Не перемещайте отдельные файлы из комплекта.

Для подключения на Windows и macOS допускается только кабель USB Type-A <-> USB Type-A.
Кабели USB Type-C <-> USB Type-A и USB Type-C <-> USB Type-C для установки не подходят.
При необходимости допускается подключение кабеля Type-A <-> Type-A через переходник или USB-хаб.

WINDOWS
------------------------------------------------------------
1. Установите ADB-драйвер устройства, если Windows ещё не видит головное устройство.
2. Подключите устройство кабелем USB Type-A <-> USB Type-A согласно общему правилу выше.
   Разблокируйте устройство и подтвердите разрешение USB debugging, если появится системный запрос.
3. Запустите install.bat двойным щелчком или из обычной командной строки.
   Скрипт не задаёт вопросов и не ждёт нажатий клавиш.
4. Дождитесь сообщения "Installation complete" и перезагрузки устройства.
5. Yandex DNS не входит в основную установку. После завершения основной установки и загрузки
   устройства отдельно запустите install-yandex-dns.bat. Эта настройка позволяет интернету работать
   в режиме белых списков для сервисов, которые входят в эти списки.

macOS
------------------------------------------------------------
1. Установите Android Platform Tools, например командой: brew install android-platform-tools
2. Подключите устройство кабелем USB Type-A <-> USB Type-A. Кабели USB Type-C <-> USB Type-A
   и USB Type-C <-> USB Type-C не подходят. Допускается использовать переходник или USB-хаб.
3. Распакуйте архив и откройте Terminal в папке релиза.
4. При необходимости разрешите запуск: chmod +x install.sh remove.sh
5. Запустите: ./install.sh
6. В конце установки появится выбор, устанавливать ли Yandex DNS. Эта настройка позволяет интернету
   работать в режиме белых списков для сервисов, которые входят в эти списки.

Если macOS сообщает, что файл получен из неизвестного источника, не отключайте системную защиту
целиком. Разрешите конкретный файл в System Settings -> Privacy & Security или снимите quarantine
только с распакованной папки релиза: xattr -dr com.apple.quarantine /путь/к/VoyahTune

ПРОВЕРКА ADB
------------------------------------------------------------
Windows: adb.exe devices
macOS:   adb devices

Ожидается одна строка с серийным номером и состоянием "device".

Типовые состояния:
- пустой список: проверьте кабель, USB-порт, драйвер Windows и режим USB debugging;
- unauthorized: разблокируйте устройство, подтвердите RSA-ключ и повторите команду;
- offline: переподключите кабель, выполните "adb kill-server", затем "adb start-server";
- несколько устройств: отключите лишние Android-устройства и эмуляторы.

ТИПОВЫЕ ОШИБКИ УСТАНОВКИ
------------------------------------------------------------
"adb.exe is not recognized" или "adb: command not found"
Запускайте скрипт из полностью распакованной папки. На Windows adb.exe должен лежать рядом с BAT.
На macOS установите Android Platform Tools и повторно откройте Terminal.

Окно BAT мгновенно закрывается
Откройте cmd.exe, перейдите в папку релиза командой cd /d C:\путь\к\VoyahTune и запустите
install.bat вручную. Последняя строка в окне покажет настоящую ошибку. Скрипт специально не содержит
pause, поэтому не ждёт клавиатуру на сервере, в автоматическом запуске или при перенаправленном stdin.

"Access is denied", файл заблокирован антивирусом или отсутствует обязательный файл
Распакуйте архив заново целиком. Проверьте карантин антивируса. Не скачивайте отдельные BAT/APK из
сторонних источников и не смешивайте файлы разных версий.

"unauthorized", "no devices/emulators found" или ожидание на "wait-for-device"
Восстановите ADB-соединение по инструкции выше. Если install.bat ждёт устройство, безопасно закройте
окно до начала копирования файлов, исправьте соединение и запустите установку заново.

"adbd cannot run as root", "root access required"
Эта прошивка или текущее подключение не разрешает root ADB. Установщик продолжать нельзя. Проверьте,
что используется поддерживаемая прошивка и правильный диагностический USB-порт.

"/system remains read-only", "I/O error", ошибка remount или EROFS
Установщик уже пробует disable-verity, перезагрузку и remount. Если ошибка повторяется, выполните
вручную adb disable-verity, adb reboot, дождитесь полной загрузки, затем adb root и adb remount.
Если /system всё равно read-only, прошивка несовместима или загрузчик блокирует изменение раздела.

Ошибка копирования, установки APK или недостаточно места
Проверьте свободное место, стабильность кабеля и целостность архива. После восстановления соединения
повторно запустите тот же установщик: операции рассчитаны на повторный запуск.

Установка подготовлена, но устройство не перезагрузилось
Перезагрузите головное устройство вручную. Не запускайте приложения Open Voyah до перезагрузки.

YANDEX DNS НА WINDOWS
------------------------------------------------------------
install-yandex-dns.bat устанавливает только DNS-overlay и перезагружает устройство. Основной
install.bat DNS не меняет. Запускайте DNS-скрипт только после успешной основной установки.

Если найден чужой DNS-overlay, скрипт не перезаписывает его. Сначала удалите или восстановите его
штатным способом. При сообщении о broken/inconsistent state запустите remove.bat из того же комплекта,
перезагрузите устройство, снова выполните install.bat и затем install-yandex-dns.bat.

YANDEX DNS НА macOS
------------------------------------------------------------
На macOS выбор установки Yandex DNS появляется в конце работы install.sh. Подтвердите установку,
если интернет должен работать в режиме белых списков для сервисов, которые входят в эти списки.
При отказе DNS-overlay не устанавливается.

УДАЛЕНИЕ И ВОССТАНОВЛЕНИЕ
------------------------------------------------------------
Для отката используйте remove.bat на Windows или ./remove.sh на macOS из той же папки релиза, где
создана папка backup. Не удаляйте и не подменяйте backup до завершения отката. Удаление восстанавливает
управляемый Open Voyah DNS-overlay и системные файлы, затем перезагружает устройство.

Если ADB оборвался во время установки или удаления, не смешивайте версии и не удаляйте backup.
Восстановите соединение и повторите тот же скрипт из той же папки. При сообщении "Do not reboot"
не перезагружайте устройство, пока ADB не восстановлен и повторный запуск не завершился успешно.

ЧТО ПРИЛОЖИТЬ К ОТЧЁТУ ОБ ОШИБКЕ
------------------------------------------------------------
- версия архива и вариант full/light;
- версия Windows или macOS;
- полный текст вывода скрипта, начиная с первой строки с "!!!";
- вывод adb devices;
- версия VoyahOS и модель автомобиля;
- на каком шаге оборвалось USB-соединение или питание, если это произошло.

Не публикуйте серийные номера, персональные данные и содержимое пользовательских backup-файлов.
