# Установщики больше не хранятся в Packaging

Готовые бинарники перенесены в игнорируемый `Releases/` и удалены из индекса Git.
Ручной реестр tooling.json больше не используется.

```sh
./make_release.sh 3.3.0 --installers
./make_release.sh 3.3.0 --mac  # только macOS; также --windows и --linux
```

Команда собирает из исходников три установщика со встроенными APK, ADB и остальными
файлами. Без флага выпускаются классические Full/Light архивы со скриптами.

Начните с [инструкции разработчика](../../Docs/releasing.md): подготовка Android
SDK/JDK, перенос ключа подписи, обновление версий, старый и новый форматы релиза.

Отдельные сборочные инструкции:

- [macOS](../../Installer/BUILDING.md#macos-инструменты-и-отдельная-сборка);
- [Windows](../../Installer/BUILDING.md#windows-инструменты-и-отдельная-сборка);
- [Linux](../../Installer/BUILDING.md#linux-инструменты-и-отдельная-сборка);
- [создание Colima и контейнеров с нуля](../../Installer/BUILDING.md#подготовка-colima-и-контейнеров-с-нуля)
  для сборки всех платформ из macOS.
