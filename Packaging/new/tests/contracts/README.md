# Поведенческие контракты миграции

450 сценариев задают наблюдаемое поведение модулей и runtime. Значения перенесены
из прежних агентов и дополнены требованиями к native lifecycle и установке.
Последняя проверка исходной реализации до удаления: 26 JS-наборов и 302 общих
сценария. Старый JS backend больше не входит в сборку или обязательный gate.

Каждый сценарий содержит `id`, `contract`, `input`, `expected`, `agents` и
`reference`. Тестируемый процесс получает только `id`, `contract`, `input`.
Schema 1 требует для каждого ID `observed` либо `error`. Проверяются точные типы,
поля и порядок эффектов. Пропуск, unsupported или пустой ответ являются ошибкой.

Драйверы вызывают production Java-модули/registry, Go lifecycle/resident/helper,
native bootstrap controllers и Rust runtime maintenance/recipe. Подменяются
внешние OEM/ART, часы, процессы, IPC и команды устройства. Политики и управление
lifecycle не копируются в тесты; готовые ответы по ID и чтение `expected` запрещены.
Состав поставки проверяется настоящим assembler в отдельном временном каталоге
с компонентами, подменёнными на границе компилятора.

```sh
python3 Packaging/new/scripts/check_java_agents.py
```

Обязательный gate проверяет все сценарии и дополнительные unit-тесты, включая
реальные D8 DEX для графа вызовов. `build_java_agents.py` не создаёт DEX при ошибке.
Host-проверка не доказывает JNI/ptrace, восстановление регистров, OEM ABI и CAN.
Реальный hook/original/unhook, JIT, attach/cancellation и UI проверяются отдельно
на Android; окончательная совместимость функций требует проверки на автомобиле.

Готовность native runtime требует завершённого helper, освобождённого tracee и
полного ACK обязательных модулей. Quiesce ждёт drain, сверяет identity и не открывает
admission после отмены клиента. Обновление блокирует новые инъекции до новой загрузки
Android. Nullable значения старых интерфейсов (например RDS `canSkip`) сохраняются;
нормализация тестового ответа для сокрытия расхождений недопустима.
