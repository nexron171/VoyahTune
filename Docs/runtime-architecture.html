01 / ИСХОДНИКИ

Общий DEX, две native ABI

Java-модули не разделяются на 32- и 64-битные версии. Go-supervisor читает ELF target и выбирает helper/SO. Native APK — отдельное приложение; его нельзя путать с внедряемой SO.

02 / ПРОВЕРКИ НА 28.10.2026

450 контрактов + изолированные ART-прогоны

Локальная сборка компонентов прошла. На машине проверены отдельный ARM32 attach и JNI-перехваты обеих ABI. Подготовка Яндекса — 9,86 с; телефона — 1,81 с. Это не проверка всех рабочих OEM-функций.

03 / ОСТАЛОСЬ ИЗМЕРИТЬ

Работа всего комплекта и нагрузка

Итоговый комплект ещё не проверен после установки на машину. Не измерены steady-state CPU, задержки UI и снижение памяти после освобождения индекса. Ранее тестовый процесс Яндекса удерживал около 340 МиБ Java heap после GC.
