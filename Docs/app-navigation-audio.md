# Навигационный звук выбранных приложений

В разделе «Приложения и разделение экрана» → «Звук через навигационный канал»
выбираются приложения, которым нужен OEM-канал навигации. По умолчанию список пуст.
После изменения списка выбранные приложения нужно перезапустить: существующие
аудиопотоки сохраняют назначенный при создании маршрут.

## Реализация

- RestoreMode хранит список пакетов и передаёт его защищённому receiver Native;
  зеркало — `Settings.Global/voyahtune_navigation_audio_apps`.
- Загрузчик подключает отдельный модуль `navigation-audio.<package>` к основному
  процессу и процессам `<package>:<service>`. Существующие модули приложения
  сохраняются при включении и отключении звукового маршрута.
- AudioTrack и SoundPool получают атрибуты OEM stream **1**, MediaPlayer — перед
  prepare/prepareAsync и при явном назначении канала. MediaSession описывает этот
  же локальный канал. Политика приложения, ограничивающая захват звука, сохраняется.
- Параметры Android TTS копируются с назначением stream 1 и меткой пакета-источника:
  Native распознаёт такую озвучку, даже когда её воспроизводит отдельный TTS engine.
- Native отслеживает активные проигрыватели и фактическую активность канала 1.
  На это время он запрашивает OEM navigation focus: usage **12**, content **1**,
  gain **3**. Фокус освобождается через **250 мс** без активности; уровень музыки
  вручную не перезаписывается. Запросы media focus выбранного приложения
  замещаются этим владельцем, чтобы оно не переключало музыку на себя.

## Границы

Назначение stream 1 и OEM focus основаны на Qinggan API; слышимость, приглушение
и восстановление музыки требуют проверки на конкретной ГУ. Локальные JVM-тесты
и компиляции не подтверждают работу автомобиля.

Прямые OpenSL ES/AAudio-проигрыватели, обходящие перечисленные Java API, и звук
системных уведомлений через ранее созданные notification channels этим модулем
не переназначаются. Для конкретного приложения нужно проверить фактический путь.

Изменения поставляются вместе: Native APK, RestoreMode APK и обновлённый runtime.
Контракт Installer не меняется; его пересборка не требуется.
