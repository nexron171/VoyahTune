# VoyahTune 3.14.0

Релиз переходит на независимые GUI-установщики и общий payload для Full и Light.
Новые совместимые версии комплекта появляются в каталоге без переустановки GUI.

- Одна пара APK для Full и Light; режим определяется при запуске по системному флагу.
- Light удаляет hooks и Frida-инфраструктуру, обновляя приложения поверх с сохранением
  данных при совместимой подписи. Переходы между режимами доступны без обязательного
  полного удаления.
- GUI 1.0.2: тёмный интерфейс, прокручиваемая таблица релизов со статусами загрузки
  и выбора, очистка скачанных комплектов, селекторы режимов и общая кнопка «Далее».
- Скачивание показывает прогресс, объём и проверяет целостность комплекта. Каталог
  учитывает минимальную версию установщика и поддерживаемые возможности.
- Windows x64 скачивает WebView2 только при необходимости; runtime не включён в EXE.
  macOS поддерживает Intel и Apple Silicon.

Для установки скачайте GUI своей платформы. Он содержит ADB и ресурсы удаления;
`payload_3.14.0.zip` загружается из каталога или импортируется локально. Отдельный CLI
не распространяется. Android APK: versionName 3.14.0, versionCode 6.

Новые установщики не подписаны Developer ID / Authenticode. Работа нового выпуска
на автомобиле и запуск Windows проверяются отдельно; проверки сборки и тестового
интерфейса не заменяют такие испытания.
