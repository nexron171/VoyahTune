# VoyahTune 3.13.0

Добавлено раннее восстановление выбранного режима вождения при запуске Native
и пробуждении. В течение 30 секунд с первой проверки приложение опрашивает
режим раз в секунду: при Eco пробует вернуть сохранённый профиль, при совпадении
продолжает наблюдение без отправки. Ошибки чтения и отправки пропускаются,
общий срок наблюдения не продлевается.

Другой известный режим завершает наблюдение как ручной выбор. Открытие
водительской двери, переход в D и явная пользовательская команда также
останавливают ранний цикл. Общее восстановление по двери, первому D после
неё и ручному применению сохраняется, включая сохранённое состояние сервисного
режима подвески. В раннем цикле участвует только профиль вождения.

Комплекты: macOS Universal (Intel и Apple Silicon) и Windows x64. Каждый
установщик содержит Full и Light, ADB и необходимые файлы для установки.
