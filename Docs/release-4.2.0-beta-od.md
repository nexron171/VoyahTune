# VoyahTune 4.2.0-beta-od

Beta для инфраструктуры OD, подготовленная в ветке `carplay-integration`.
Встроенный CarPlay входит в APK VoyahTune; отдельное приложение DiPlay не требуется.
Контракты и границы реализации описаны в [спецификации CarPlay](carplay-diplay.md).

## Изменения

- Виджет запускает интерфейс проекции CarPlay на VirtualDisplay через его владельца
  Native. Пассивный уход с главной VoyahTune сохраняет VD и подключение; при возврате
  восстанавливается изображение.
- Добавлена отдельная кнопка ярлыка **CarPlay 1×1** в настройки главного экрана.
  Ярлык открывает CarPlay на весь экран. Переход виджет ↔ отдельная Activity
  последовательно освобождает прежний host и согласует новый размер с iPhone.
- Кнопка VoyahTune/VoyahFree в интерфейсе iPhone CarPlay возвращает на главную
  VoyahTune. Долгий тап «Все приложения» OD-дока также открывает главную,
  закрывая экраны настроек поверх неё.
- При скрытии отдельной Activity CarPlay сохраняются controller и служба сессии.
  Видеодекодер паркуется до возврата поверхности; изменение размера скрытого окна
  не запускает переподключение.
- Добавлена настройка **«Смена темы CarPlay по освещенности»**, выбирающая режим
  автомобильного SWReason. Он переключает только проекцию CarPlay; оформление
  VoyahTune/DiPlay остаётся независимым.
- Для кнопок громкости руля добавлен выбор активного OEM-канала CarPlay:
  звонки, Siri, подсказки навигации и музыка. После окончания подсказки канал
  навигации освобождает фокус. В настройках CarPlay добавлены четыре ползунка
  фактической громкости каналов.
- Native при создании службы в OD запрашивает включение Wi-Fi. Отказ записывается
  в журнал; ручное выключение сохраняется до следующего создания службы.

## Совместимость и проверка

Минимальный Installer — **1.7.0**. Установщик сохраняет эту версию и не требует
пересборки: исполняемый GUI, root-служба и контракт установки не менялись.
`versions.json.voyahtune` сохраняет stable-версию 4.0.1; номер beta задаётся сборке.
Для новой записи beta-каталога `minimumOtaVersion` — **4.2.0**: прежние записи этого
каталога не содержат минимумов совместимости. Первичная установка beta выполняется
через совместимый Installer; основной OTA-каталог не изменяется.

Целевые локальные JVM/JS-проверки покрывают протоколы, выбор дисплея/host, владение
сессией, парковку видеовывода, политику аудиофокуса и тему. UI-тесты не выполнялись.
Пользователь подтвердил переключение темы CarPlay по фарам в ранее установленной
сборке; новый переключатель, четыре ползунка и текущие изменения фонового режима
ещё не проверены на ГУ. Локальные проверки не подтверждают доступ к OEM Binder,
работу рулевых кнопок и непрерывность реального соединения с iPhone.

Beta-каталог публикуется в ветке `carplay-integration`. Это не меняет встроенный
основной URL GUI/OTA и не продвигает beta в основной каталог. Подробности установки
и выпуска — [релизный процесс](releasing.md) и [Yandex S3](releasing-s3.md).
