# VoyahTune 4.3.0-beta-od

Beta для инфраструктуры OD. Изменения относительно 4.2.0-beta-od:

- Встроенный DiPlay обновлён до 0.2.17 с сохранением интеграции VoyahTune: SWReason, аудиоканалы Native, фоновые сессии и переходы между окном и отдельным экраном.
- Настройки CarPlay вынесены в собственную секцию после быстрого доступа: режим «ярлык» 1×1 либо «окно» с выбором размера и автоматическим запуском.
- Обновлено оформление стартового экрана и подключения: тёмный значок, компактные плитки, кнопка отмены подключения. Скрыты ненужные настройки самостоятельного DiPlay; GPS и SWReason включены по умолчанию только при отсутствии сохранённого выбора.
- Для кнопок «Домой» и «Все приложения» в доке добавлено независимое переключение действий короткого и долгого нажатия. Ярлык CarPlay доступен для назначения в слот дока.
- Новые фоновые обновления и OEM-функции DiPlay заблокированы для встроенного режима, управление автомобилем остаётся у Native.

Минимальный Installer — **1.7.0**, минимум VoyahTune для OTA — **4.2.0**.
Installer не изменён и не требует пересборки. Stable-версия в versions.json сохраняется.

Сборка и целевые JVM/JS-проверки выполнены локально; обновление движка установлено
на эмулятор. Проверка 4.3.0 с реальным iPhone и автомобилем не выполнялась.
Технические особенности миграции описаны в [спецификации CarPlay](carplay-diplay.md).
