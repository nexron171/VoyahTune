# VoyahTune 3.16.0

## Изменения

- Выбранные пользователем режимы вождения и энергии отделены от наблюдаемого
  состояния автомобиля: штатный сброс больше не подменяет сохранённый выбор.
- Восстановление режимов использует стартовую команду и перехваты известных
  OEM-сбросов; повторное применение режимов из проходов Native по двери/D удалено.
- При выходе из Forced EV восстанавливается настроенный режим энергии.
- Улучшено восстановление агентов после ошибок и перезапуска OEM-процессов.
  Удалён опасный для исследованной H97X ART обход Java heap.

Подробности и границы проверки на головном устройстве описаны в
[алгоритме восстановления](early-drive-mode-restore.md) и
[описании ACC-перехвата](acc-restore-hook.md). Эти проверки исходных исправлений
не заменяют отдельную проверку установки нового архива 3.16.0.

## Состав выпуска

Общий payload 3.16.0 предназначен для совместимого Installer 1.2.0 и OTA.
Установщики собраны отдельно для macOS Universal (Apple Silicon и Intel),
Windows x64 и Windows x86. Версия установщика остаётся 1.2.0; payload и
установщики имеют независимые версии. Windows x86 предназначен для 32-битной
Windows 10. Проверка сборки не подтверждает запуск на Windows или работу на машине.

Файлы выпуска размещаются в `voyahtune/v3.16.0/` в Yandex Object Storage.
Каталог OTA хранится в [Releases/ota/index.json](../Releases/ota/index.json).
Установщики скачивают payload из каталога или импортируют локальный ZIP.
