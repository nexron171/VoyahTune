# VoyahTune 3.19.0

## Изменения после 3.18.0

- Из настроек удалена активация штатного меню Apollo. Настройки TLC,
  распознавания светофоров, звука зелёного сигнала и дорожных знаков сохранены.
- Новый компьютерный установщик и новая root-служба Updater перед заменой APK
  выключают старую активацию. Изменённые XML сохраняются в
  `/data/local/voyahtune-apollo-backup/`; остальные цели Apollo Tech не меняются.
- RestoreMode и Native удаляют устаревшую настройку при запуске. Это также
  защищает обновление через ранее установленную OTA-службу, которая не знает
  нового шага миграции.
- После успешного обновления интерфейс новой службы Updater показывает кнопку
  «Завершить» для возврата к проверке обновлений.

## Совместимость и проверка

Требования payload остаются совместимыми с Installer 1.2.0 и более новым:
увеличение минимума заблокировало бы OTA через ранее установленную службу.
Для предустановочной миграции и нового экрана Updater нужна установка через
пересобранный компьютерный установщик. OTA сохраняет прежние executable и APK
Updater, поэтому кнопку «Завершить» после одного OTA не добавляет.

Изменён порядок установки в GUI и классических скриптах, поэтому установщики
для macOS Universal, Windows x64 и Windows x86 пересобираются. Версия Installer
остаётся 1.3.1: формат payload и поддерживаемые операции не изменились.

Локальные тесты и проверка архивов не подтверждают восстановление экрана на
автомобиле. Испытание на официальных SE и Sport+ 2025–2026 с Android 11
выполняется отдельно.
