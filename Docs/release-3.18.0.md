# VoyahTune 3.18.0

## Изменения после 3.17.0

- Восстановлена прежняя логика автосвета. Показания и события освещения доступны
  только в разделе отладочной информации; диагностический экран показывает
  полученные значения и состояние подключения, не выдавая их за выполнение
  команды фарами.
- Упрощена синхронизация сохранённой конфигурации после запуска и пробуждения
  автомобиля вместе с возвратом прежней логики автосвета.
- Релизный APK RestoreMode теперь содержит только native-библиотеки `arm64-v8a`.
  `x86_64` остаётся в debug APK для эмуляторов.

## Состав и проверка

Релиз распространяется как общий payload для существующего совместимого
Installer. Изменения его исполняемого кода и встроенных ресурсов в этом выпуске
не требуются, поэтому отдельная пересборка установщика не нужна. Каталог OTA
содержит [запись payload](../Releases/ota/index.json).

Локальные тесты и сборка проверяют код и состав архива, но не подтверждают
установку и работу на автомобиле. Публикация и её проверка отмечаются отдельно
после фактического выполнения.
