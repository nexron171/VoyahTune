# Независимый интерфейс OTA

Интерфейс работает в отдельном APK `ru.big.town.updater`, Activity
`ru.big.town.updater.UpdaterActivity`. Его процесс и UID независимы от RestoreMode.
Настройки RestoreMode открывают эту Activity напрямую.
Разметка и состояния находятся в [Updater/ui](../Updater/ui). Только IPC-клиенты
из [Updater/client](../Updater/client) используются также RestoreMode.
Загрузкой, журналом, установкой и reboot владеет самостоятельная root-служба.

## Установка и обновление

Первый переход на эту схему выполняется через USB с актуальным Installer из `versions.json`.
Установщик размещает APK в
`/system/priv-app/VoyahTuneUpdater/VoyahTuneUpdater.apk` и регистрирует через
PackageManager. APK подписывается тем же ключом, что Native и RestoreMode.

OTA сохраняет установленные APK Updater, root executable, init rc и bootstrap.
Самообновления интерфейса нет: изменение этих компонентов доставляется через USB.
Обновление RestoreMode не закрывает экран Updater.

## Принудительная остановка

USB и OTA сохраняют блокировку запуска, затем принудительно завершают собственный
loader, helpers, Native, RestoreMode и работающий RunYN. Подтверждение quiesce/drain
от Java-агентов не требуется. Общий helper проверяет принадлежность процесса,
PID/startTicks и UID и ограниченно ждёт фактического завершения.
Root-служба и интерфейс Updater остаются работать. `system_server` и OEM-процессы
со встроенными агентами остаются до reboot: для установки APK нужен PackageManager.

Файлы заменяются через stage и rename на целевой файловой системе, затем
устанавливаются приложения и выполняются sync и обязательная перезагрузка.
После начала принудительной остановки ошибка также приводит к попытке reboot;
первичная ошибка и блокировка сохраняются для USB-восстановления. Ошибка не
выдаётся за успешную установку. Native/RestoreMode APK не резервируются.

## IPC и проверки

`UpdateService` отделяет экран от исполнителя. `RootClient` отправляет JSON schema 1
по `/dev/socket/voyahtune_updater` и проверяет UID 0. Служба разрешает отдельные
уникальные UID Updater и RestoreMode для общих настроек и диагностики, проверяя
активный APK и подпись относительно системного Native. Внешний Intent не задаёт
endpoint, архив или shell-команду.

Installer проверяет ответ root-службы, активный APK Updater и доступность Activity.
Единственный допуск OTA остаётся `minimumOtaVersion`; первое обновление root-службы
требует USB, минимум определяется версией первого совместимого релиза при сборке.
[Процесс выпуска](releasing.md).

Локальные проверки охватывают общий порядок обслуживания, принудительный stop с
сохранением Updater/OEM, авторизацию клиентов и ошибки финализации. Общая библиотека
UI имеет JVM- и socket/instrumentation-тесты. Реальную остановку init-процессов,
замену APK и поведение автомобиля проверяют отдельно на ГУ.
