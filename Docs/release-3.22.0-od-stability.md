# История OD-доработок VoyahTune 3.22.0

Ниже зафиксированы изменения и выпуск до переноса ветки на общий `master`.
Опубликованные `3.22.0` и Installer `1.4.1` относятся к прежнему OD-составу.
Текущие исходники используют Installer **1.5.0**, capability `infrastructure-v1`
и явный суффикс `-od`; все описанные доработки ограничены OD.
При переносе публикация и повторная сборка не выполнялись.
Текущий состав PI/OD описан в [заметках релиза](release-3.22.0.md).

## Изменения

- VD/freeform: ожидание готовности служб system_server до установки хуков,
  ограниченный срок подготовки и откат при ошибке. Loader проверяет подтверждение
  агента для точного поколения процесса; exit 0 без ready не означает успех.
- DPI: целостный снимок настроек, без чтения Settings в горячих callbacks;
  защита от вложенного обновления одной задачи. Native поддерживает полный список
  DPI-пакетов при запуске приложения и записи дока.
- Сон и пробуждение: повторные события экрана сохраняют корректное состояние,
  pending actions отменяются, серия обновлений настроек объединяется.
- Геометрия: проверка полей перед мутациями, независимое восстановление общих
  полей и ограниченный слабый кэш оригинальных размеров окон. Отключение
  fullscreen/freeform восстанавливает размеры в проверенном контексте WindowManager.

Подробности — [системная геометрия](system-server-geometry.md) и
[параллельный loader](parallel-hook-loader.md#готовность-vd-в-3220).

## Дополнения beta от 4 октября 2026

- Рекуперация: запоминание явного выбора штатного меню, руля и голоса; раннее
  восстановление в ACC/reset и последующий TX77 Native. В Snow минимум задаёт
  автомобиль. Автоматические обратные события не затирают сохранённый выбор.
- Радио: сохранённая станция выбирается в интерфейсе без аудиофокуса и запуска
  звука при раннем ACC, последующем Native и позднем запуске RdsApp. Реальная
  настройка тюнера выполняется при воспроизведении.
- Apollo: отдельные опции применяются сразу после изменения и в ACC-проходе,
  независимо от удалённого общего выключателя. Возможности отправляются перед
  PLC/GLA/звуком зелёного/TSR. Аппаратный результат требует проверки на автомобиле.
- Диагностика света: видимый экран обновляет OEM RSM-состояние раз в секунду.
- Installer 1.4.1: проверка Updater после установки ждёт готовности системных
  служб и повторного устойчивого результата; перезапуск system_server больше
  не трактуется как доказательство повреждения регистрации пакета.
- Процент SREV исключён из доработки; сохранение/восстановление процента не добавлено.

Подробный порядок — [таблица восстановления](settings-restoration-matrix.md).

## Проверки и ограничения

Изменения восстановления проверены 348 JVM-тестами Native и 128 RestoreMode,
48 сценариями RDS и 9 сценариями durable ACC. Собраны оба debug APK; прошли
контракты ACC/reset/feedback/Apollo/app-client, локальные ссылки и git diff --check.
Геометрия сохраняет физические дисплеи 0/1, compact viewport, док и VD-сплит.
Распространяемая сборка выполнена из чистого revision
`c3ce8229501e60d57113629c30132355decca62d`. Проверены все 29 артефактов payload,
соответствие ZIP исходной папке, подписи APK, подписанный recipe и build metadata.
Native и RestoreMode имеют versionName `3.22.0`, versionCode `3022000`;
Updater сохраняет версию `0.4.0`.

Для Installer прошли 40 Rust-тестов, Svelte check, 26 тестов публикации и 9
интеграционных сценариев с fake ADB: недоступность Android, перезапуск до/во время
восстановления Updater, сохранение данных и обработка настоящей ошибки.
У конечных NSIS и macOS ZIP проверены распакованные bundle, архитектуры GUI/ADB
и контрольные суммы. У macOS проверена ad-hoc подпись; Developer ID и notarization
отсутствуют, Windows-пакеты без Authenticode. Запуск Windows GUI не проверялся.

Основная целевая платформа — официальные SE и Sport+ 2025–2026, Android 11.
Новые изменения на автомобиле не испытывались. Принятие Binder-команды не
доказывает её физическое выполнение. Причина прежнего SIGSEGV system_server
не установлена; локальные проверки не доказывают устранение падения ART/Frida.

## Состав и публикация

Релиз предназначен для отдельного [beta-каталога](../Releases/ota/index-beta.json).
Основной каталог не изменён. Общий payload имеет версию 3.22.0; ранее
опубликованные байты и запись 3.22.0 заменены по явному поручению пользователя.

Для полного состава прежней OD-ветки GUI пересобирался из-за изменения postflight
в Rust-движке. По поручению о новой версии собран Installer **1.4.1**:
macOS Universal, Windows x64 и Windows x86, без встроенного payload. Минимум
Installer в payload остаётся 1.2.0: контракт установки не расширяется.

не скачивались; это не независимый пересчёт SHA-256 удалённых байтов.

Если прежняя 3.22.0 уже установлена, для этой сборки используется «Проверить релиз
для повторной установки» в настройках Updater с выбранным beta-каталогом.
Обычная проверка обновлений не предлагает ту же версию автоматически.
