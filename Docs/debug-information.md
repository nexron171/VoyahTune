# Отладочная информация

Переключатель «Режим отладки» в разделе «Другое» показывает блок
«Отладочная информация». Значение сохраняется в настройках RestoreMode; блок
появляется и скрывается сразу после переключения. Пока показатели не добавлены,
блок показывает сообщение «Показатели пока не добавлены».

Переключатель управляет только видимостью блока. Отправка CAN-кадров и OEM-команд,
чтение состояния автомобиля, восстановление режимов, управление подвеской и
сервисные действия не зависят от него. Прежний код эмуляции команд удалён.

Колонка 12 `debugMode` в ContentProvider сохранена для совместимости с прежним
форматом ответа, но всегда равна 0. Это позволяет ранее внедрённым хукам не
отменять восстановление режимов при включённом новом интерфейсном переключателе.
Новые диагностические показатели можно добавлять в блок по мере согласования
их источников и смысла; пустое состояние не выдаёт фиктивные значения автомобиля.
