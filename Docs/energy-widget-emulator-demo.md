# Временный экран тестирования виджетов

Временная доработка для визуальной проверки, добавленная отдельным коммитом
по запросу пользователя. После тестирования этот коммит можно отменить
через `git revert`: постоянные изменения виджетов в него не входят.
После отмены нужно пересобрать и переустановить обычный APK; уже установленная
демосборка сама от изменения Git не обновится.

`EnergyWidgetDemoActivity` находится только в `src/debug`, отдельная запись
манифеста и синтетические данные не попадают в release APK. Главный экран
`MainActivity` при обычном запуске продолжает получать данные Native.
Демо-вход разрешён только на debug-сборке с аппаратной платформой эмулятора
`ranchu` или `goldfish`; на устройстве автомобиля он не запускается.

Экран использует настоящие `MainActivity`, сетку, настройки и `EnergyWidgetView`.
Native для него не нужен. Демоснимок обновляет время свежести каждую секунду,
а значения воспроизводимы: 1501 точка последних 150 км маршрута длиной 180 км,
47,3% батареи, 30% топлива, ODO 15417 км, поездка 30 км / 00:42:18,
давления 2,6/2,7/2,7/2,7 bar. История содержит зарядки и заправки, включая
заправку на 162 км внутри текущей поездки, как HTML-прототип.

Средние периода рассчитывает обычный код виджета из накопленных снижений,
средние поездки — тот же общий расчёт с выбранными ёмкостями. При изменении
43 кВт·ч / 56 л в настройках оценки пересчитываются. Первоначальная раскладка
8×3, 8×2, 4×4 и 4×1 применяется один раз; затем размеры, цвет и масштаб
остаются пользовательскими. Слева в свободной области дока находятся
пометка эмулятора и кнопка «Настройки».

## Сборка и запуск

Из `RestoreMode/` с настроенными JDK 21 и Android SDK:

```sh
./gradlew testDebugUnitTest assembleDebug \
  -PvoyahReleaseVersion=3.22.0-energy-emulator-demo
```

Установить только на выбранный эмулятор, предварительно убедившись, что
`getprop ro.kernel.qemu` возвращает `1`:

```sh
adb -s emulator-5554 shell getprop ro.kernel.qemu
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 shell am start --user current \
  -n ru.big.town.restoremode/.EnergyWidgetDemoActivity
```

Для проверки используется Android Automotive 13 / API 33 / ARM64 с основным
дисплеем 1920×720, 160 dpi и отдельным кластером 400×600. Это проверка
отрисовки и взаимодействий; OEM/CAN, приём данных автомобиля и восстановление
истории Native таким запуском не проверяются. Native не устанавливается,
резервные копии APK не создаются. Пересборка установщика не требуется.

Проверки 4 октября 2026: 114 JVM-тестов RestoreMode, debug-сборка,
компиляция Java и манифеста release. В release отсутствуют демоклассы и вход
демоактивности. На эмуляторе проверены оба масштаба 75/150 км, выбор/снятие
маркера, сохранение масштаба после перезапуска, переход в настройки,
компактные размеры 4×3, 4×2, 2×3 и 2×1. Нижняя область системной навигации
в демоактивности прозрачна, поэтому не перекрывает поездку и одометр.
